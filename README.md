# Relocate in comfort

Адаптивный веб-сайт для планирования переезда или длительных путешествий.  
Платформа собирает структурированную информацию о странах: стоимость жизни, визовая политика, климат, цифровая среда, медицина, образование и культурные особенности.

🔗 **Ссылка на веб-сайт:** [https://relocate-omega.vercel.app/](https://relocate-omega.vercel.app/)


## Технологии

### Фронтенд
- **React 19** — компонентная архитектура
- **React Router** — маршрутизация
- **CSS Modules** — изолированные стили
- **Vite** — быстрая сборка
- **react-transition-group** — плавные анимации

### Бэкенд
- **Node.js + Express.js** — REST API
- **MongoDB** — документоориентированная база данных
- **JWT** — аутентификация
- **bcrypt** — хэширование паролей

### Деплой
- **Vercel** — фронтенд
- **Render** — бэкенд
- **MongoDB Atlas** — облачная база данных

## 🛠️ Установка и запуск

### Требования
- Node.js (v18+)
- MongoDB (локально или Atlas)

1. Клонирование репозитория
```bash
git clone https://github.com/gina-eifman/relocate.git
cd relocate
```
2. Настройка бэкенда
```bash
bash
cd backend
npm install
cp .env.example .env
npm run dev
```
3. Настройка фронтенда
```bash
cd ../frontend
npm install
npm run dev
```
4. Переменные окружения (бэкенд)
```js
PORT=5000
MONGO_DB=mongodb://127.0.0.1:27017/relocatedb
JWT_SECRET=your-secret-key
```


## Основной функционал

- Поиск стран по названию и ключевым словам
- Фильтрация по категориям (климат, стоимость жизни, безопасность, цифровая среда и др.)
- Избранное — сохранение понравившихся стран
- Пользовательские коллекции — создание подборок стран
- Личный профиль — редактирование данных и аватара
- Аутентификация через JWT

### Адаптивность:
Сайт корректно отображается на:
- мобильных телефонах (320px+)
- планшетах (768px+)
- ноутбуках (1024px+)
- широких экранах (1440px+)

Используются clamp(), vw/vh, процентные размеры и медиазапросы.
